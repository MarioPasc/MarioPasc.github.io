# CLAUDE.md

This file provides guidance to Claude Code when working with this repository.

## Project Overview

Jekyll-based academic homepage of Mario Pascual González (MSc student in AI at
UAM; research trainee, ICAI group, University of Málaga). Hosted on GitHub
Pages at `https://mariopasc.github.io/`, built by the Pages builder from the
`main` branch. Pages: Home, Publications, CV, Blog.

The site is deliberately minimal: one column of text, no theme, one plain
CSS file, and JavaScript only for the light/dark toggle and opt-in MathJax. Content lives in
`_data/` YAML files; pages only arrange it.

## Design System

- **Font**: Source Serif 4 (self-hosted in `assets/fonts/`, SIL OFL) for all text; system sans-serif for navigation and small metadata; system monospace for code
- **Palette**: near-black text on white, one muted grey, one dark-blue link colour
- **Theme**: light by default (also when the OS is dark); a text button in the header switches to dark via `<html data-theme="dark">`, remembered in `localStorage`
- **Layout**: single column, `--measure: 46rem`; header with name left and nav right; date/label column grids for news, CV and publications
- **Not used, on purpose**: cards, shadows, gradients, animations, icons, badges, third-party fonts or trackers

## Development Commands

Run from the repository root (`git rev-parse --show-toplevel`). On machines
with rbenv, first run `export PATH="$HOME/.rbenv/bin:$PATH" && eval "$(rbenv init - bash)"`.

```bash
bundle install                          # Install dependencies
bundle exec jekyll serve --livereload   # Local dev server at localhost:4000
bundle exec jekyll build                # Build to _site/
python3 scripts/update_metrics.py       # Refresh Google Scholar metrics
npm install && npm run lint             # Stylelint on assets/css/*.css
lsof -i :4000                           # Check for port conflicts
```

### Key Config

- **Collections**: `blog` → `content/_blog/` (`collections_dir: content`)
- **Plugins**: `jekyll-sitemap` only (Pages-whitelisted)
- **Markdown**: kramdown with GFM input; Rouge highlighting at build time
- **`theme: null`**: stops the Pages builder from injecting `jekyll-theme-primer`
- **Compatibility**: templates must work on Jekyll 3.10 + Liquid 4 (the Pages builder) and Jekyll 4 (local). No Sass, no custom plugins.

## Content Conventions

### Profile, news, CV

Edit `_data/profile.yml`, `_data/news.yml` (newest first; home shows six, the
rest fold under "Earlier news") and `_data/cv.yml`. The CV mirrors the LaTeX
CV; never publish phone numbers, national ID numbers, home addresses or
referee contact details.

### Publications (`_data/publications.yml`)

Groups in display order: Journal articles, Manuscripts under review,
Preprints, Conference proceedings, Communications at clinical congresses.
Item fields:

| Field | Required | Description |
|-------|----------|-------------|
| `id` | Yes | Short label and HTML anchor (`J1`, `R1`, `P1`, `C1`, …) |
| `authors` | Yes | `M. Pascual-González, A. Other`; the string equal to `profile.citation_name` is bolded |
| `title` | Yes | Sentence case |
| `venue` | Yes | Journal, conference, or `arXiv preprint arXiv:<id>` |
| `details` | No | Volume, pages, status |
| `year` | Yes | Year |
| `note` | No | One line (HTML allowed), e.g. awards, corresponding author |
| `selected` | No | `true` shows the entry on the home page |
| `links` | No | List of `{label, url}`: DOI, arXiv, code, PyPI, Zenodo, PDF |
| `bibtex` | No | Literal block; shown in a collapsible element |

Link news and CV entries to a publication with `/publications/#<id>`.

### Blog posts (`content/_blog/`)

```yaml
---
title: "Post Title"
date: YYYY-MM-DD
tag: free-text label shown next to the date (optional)
description: "One or two sentences, used for the meta description"
math: true            # optional: loads MathJax ($...$, $$...$$)
---
```

Code uses fenced blocks with a language name. Images go in
`assets/images/blog/<post>/`. Files starting with `_` are not published.

### Citation metrics

`_data/metrics.yml` is generated; refresh it with
`python3 scripts/update_metrics.py` before pushing. Google Scholar blocks
CI runners, so this is not automated.

## Style & Code Guidelines

### HTML/Liquid

- Semantic HTML5 (`<article>`, `<section>`, `<nav>`, `<header>`, `<footer>`); accessibility attributes (`aria-label`, `aria-current`)
- Put content in `_data/`, presentation in `_includes/`/`_layouts/`; avoid hard-coding facts in templates

### CSS

- Plain CSS in `assets/css/main.css`; use the custom properties on `:root`
- Every colour needs a dark value in the `:root[data-theme="dark"]` block; print always uses the light palette
- Grid columns use `minmax(0, 1fr)` so long content (BibTeX, URLs) cannot widen the page
- Keep it lint-clean: `npm run lint`

### JavaScript

- Only `assets/js/theme.js` (toggle) and the inline pre-paint snippet in `_layouts/default.html`; plain ES5, no build step
- Everything else must work without JavaScript (e.g. `<details>`); the toggle button stays `hidden` if the script does not run

## Agentic Workflow

When making any visual or structural change, follow this loop:

1. **Edit** — Make the code change
2. **Build check** — `bundle exec jekyll build 2>&1`
3. **Start server** — `bundle exec jekyll serve` if not running
4. **Visual inspection** — Playwright screenshots at mobile (375×812), tablet (768×1024), desktop (1440×900); dark mode by clicking the header toggle. Check that no page scrolls horizontally at 360 px.
5. **Fix issues** — Repeat from step 2
6. **Commit and push** — Conventional commits (`feat:`, `fix:`, `style:`, `content:`, `refactor:`)
7. **Verify deploy** — Check the "pages build and deployment" run, then screenshot production

### Commit Conventions

Types: `feat`, `fix`, `style`, `content`, `refactor`, `docs`, `chore`

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `jekyll serve` fails with address in use | `lsof -i :4000` then stop the process |
| Formula not rendering | Add `math: true` to the page front matter |
| Builds locally, fails on Pages | Feature not in Jekyll 3.10 / Liquid 4, or a non-whitelisted plugin |
| Unexpected `assets/css/style.css` in the build | `theme: null` missing from `_config.yml` |
| Site opens dark for a visitor | Expected only if they chose dark before (`localStorage.theme`); the default is light |
| Page scrolls sideways on mobile | A grid/flex child without `min-width: 0`, or a long unbreakable string |
| `git push` over HTTPS asks for a username | Push over SSH: `git@github.com:MarioPasc/MarioPasc.github.io.git` |
